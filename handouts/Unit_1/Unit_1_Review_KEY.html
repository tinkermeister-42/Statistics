Unit Review - Unit 1: Displaying One Variable - DHS Statistics
Teacher Key: answers in red

One data set, every tool. 11 students said how many movies they watched last month.

3, 1, 15, 2, 4, 2, 6, 1, 3, 5, 2

1.1 Show the data.

A dot plot puts one dot on the number line for each value.

Most students watched 1 to 6 movies. One student watched 15.
1.2 Find the center.

Σ\Sigma means add up.
nn is the number of values.
x‾\bar{x} is the mean.

x‾=Σxn=4411=4\bar{x} = \dfrac{\Sigma x}{n} = \dfrac{44}{11} = 4 movies

In order: 1, 1, 2, 2, 2, 3, 3, 4, 5, 6, 15.   Median =3= 3 movies

The tail is on the right. It pulls the mean up, so mean >> median.
The shape is skewed right.
1.3 Find the spread.

Odd number of values? Leave the median out of both halves.

Lower half 1, 1, 2, 2, 2.   Q1 =2= 2

Upper half 3, 4, 5, 6, 15.   Q3 =5= 5

Five-number summary:  1,  2,  3,  5,  15

IQR =Q3−Q1=5−2=3= Q_3 - Q_1 = 5 - 2 = 3
1.4 Check for outliers.

A value below the lower fence or above the upper fence is an outlier.

Lower fence =Q1−1.5×IQR=2−4.5=−2.5= Q_1 - 1.5 \times \text{IQR} = 2 - 4.5 = -2.5

Upper fence =Q3+1.5×IQR=5+4.5=9.5= Q_3 + 1.5 \times \text{IQR} = 5 + 4.5 = 9.5

15 is above 9.5, so 15 is an outlier. On a box plot it is a dot. The whisker stops at 6.

Read every box plot the same way. Each of the 4 parts holds about 25% of the data. A long part means the values are spread out, not that there are more of them.

8. I use the 1.5 ×\times IQR rule to find outliers.
11 students scored these points on a test.
65, 30, 72, 61, 68, 78, 63, 66, 60, 69, 64
  1. Find Q1, Q3, and the IQR.
    In order: 30, 60, 61, 63, 64, 65, 66, 68, 69, 72, 78.   Lower half 30, 60, 61, 63, 64: Q1 =61= 61
    Upper half 66, 68, 69, 72, 78: Q3 =69= 69.   IQR =69−61=8= 69 - 61 = 8
  2. Find the lower fence and the upper fence.
    1.5×8=121.5 \times 8 = 12.   Lower fence =61−12=49= 61 - 12 = 49.   Upper fence =69+12=81= 69 + 12 = 81
  3. Which values are outliers? Explain.
    30 is an outlier, because it is below 49. 78 is not an outlier, because it is not above 81.
