1.1  Frequency Tables, Dot Plots, and Histograms

Mini Lesson - Unit 1: Displaying One Variable - DHS Statistics
NameDatePeriod

Frequency means how many times something happens. These three tools all show frequency.

Each value gets a row. Each value gets a spot on a number line. Values are put in groups (bins).
Make a tally mark for each data point, then count. One dot = one data point. Stack the dots. Bars touch. No gaps between groups.
Frequency column = how many. Height of the stack = how many. Bar height = how many in that group.

Histogram rule: If a number is on a line between two bars, it goes in the bar on the right. Example: 160 goes in the 160 to 170 bar.

The frequency table and dot plot above show the same data. Check: 2 + 4 + 3 + 1 + 1 = 11 students.

Every time you read a graph: read the title, read both axis labels, then check the scale.
