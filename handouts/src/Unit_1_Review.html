One data set, every tool. 11 students said how many movies they watched last month.

3, 1, 15, 2, 4, 2, 6, 1, 3, 5, 2

1.1 Show the data.

A dot plot puts one dot on the number line for each value.

 {{fig Unit_1/Review_dot_plot_movies}}

Most students watched 1 to 6 movies. One student watched 15.
1.2 Find the center.

$\Sigma$ means add up.
$n$ is the number of values.
$\bar{x}$ is the mean.

$\bar{x} = \dfrac{\Sigma x}{n} = \dfrac{44}{11} = 4$ movies

In order: 1, 1, 2, 2, 2, 3, 3, 4, 5, 6, 15.   Median $= 3$ movies

The tail is on the right. It pulls the mean up, so mean $>$ median.
The shape is skewed right.
1.3 Find the spread.

Odd number of values? Leave the median out of both halves.

Lower half 1, 1, 2, 2, 2.   Q1 $= 2$

Upper half 3, 4, 5, 6, 15.   Q3 $= 5$

Five-number summary:  1,  2,  3,  5,  15

IQR $= Q_3 - Q_1 = 5 - 2 = 3$
1.4 Check for outliers.

A value below the lower fence or above the upper fence is an outlier.

Lower fence $= Q_1 - 1.5 \times \text{IQR} = 2 - 4.5 = -2.5$

Upper fence $= Q_3 + 1.5 \times \text{IQR} = 5 + 4.5 = 9.5$

15 is above 9.5, so 15 is an outlier. On a box plot it is a dot. The whisker stops at 6.

{{fig Unit_1/Review_box_plot_movies}}

Read every box plot the same way. Each of the 4 parts holds about 25% of the data. A long part means the values are spread out, not that there are more of them.

Scores on a 20-point quiz:

15, 18, 12, 20, 17, 14, 19, 9

  1. Find $\bar{x}$.
    {{a}}$\Sigma x = 124$,  $n = 8$,  $\bar{x} = \frac{124}{8} = 15.5$ points{{/a}}
  2. Find the median.
    {{a}}In order: 9, 12, 14, 15, 17, 18, 19, 20.   Median $= (15 + 17) \div 2 = 16$ points{{/a}}
  3. A data set has $\Sigma x = 96$ and $n = 8$. Find $\bar{x}$. {{a}}$\bar{x} = \frac{96}{8} = 12${{/a}}
  4. Ana's first four quiz scores are 80, 75, 90, and 85. What score does she need on the fifth quiz so that the mean of all five scores is 84?
    {{a}}All five must add to $\Sigma x = 5 \times 84 = 420$.   The first four add to $80 + 75 + 90 + 85 = 330$.
    $420 - 330 = 90$. She needs a 90.{{/a}}
