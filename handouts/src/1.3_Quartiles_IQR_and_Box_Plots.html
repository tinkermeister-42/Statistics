Quartiles cut the data into 4 parts with the same number of values. Each part has about 25% of the data.

How to find the quartilesFive-number summary
1. Put the data in order.
2. Find the median. It splits the data into a lower half and an upper half.
3. Q1 = median of the lower half.
4. Q3 = median of the upper half.
Odd number of values? Leave the median out of both halves.		 Minimum

IQR = Q3 $-$ Q1
The IQR (interquartile range) is how spread out the middle half of the data is.

Example 1: odd number of values (11)

3, 4, 6, 7, 9, 10, 12, 13, 15, 18, 20     Median = 10 (leave it out of the halves)

Lower half: 3, 4, 6, 7, 9  $\rightarrow$  Q1 = 6     Upper half: 12, 13, 15, 18, 20  $\rightarrow$  Q3 = 15

IQR = 15 $-$ 6 = 9

Example 2: even number of values (10)

1, 3, 4, 6, 7, 9, 10, 12, 14, 18     Median = (7 + 9) $\div$ 2 = 8

Lower half: 1, 3, 4, 6, 7  $\rightarrow$  Q1 = 4     Upper half: 9, 10, 12, 14, 18  $\rightarrow$  Q3 = 12

IQR = 12 $-$ 4 = 8

Gotcha
The 4 parts have the same number of values, not the same width. A short part means the values are packed close together.

6. Look at these two data sets.
Set A:1, 2, 3, 4, 5, 6, 7
Set B:1, 2, 3, 4, 5, 6, 70
  1. Find the IQR of each set.
    {{a}}Both: Q1 = 2, Q3 = 6, IQR = 4{{/a}}
  2. Find the range (max $-$ min) of each set.
    {{a}}A: 7 $-$ 1 = 6.   B: 70 $-$ 1 = 69{{/a}}
  3. One number changed. Which measure of spread changed a lot? Which did not change? Why?
    {{a}}The range changed a lot. The IQR did not change. The IQR only uses the middle half. One extreme value does not move it much. The median works the same way: one extreme value moves the mean a lot, but not the median.{{/a}}
