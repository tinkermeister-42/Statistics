Expected value:    E(X)=Σx⋅P(x)E(X) = \Sigma\, x \cdot P(x)
E(X)E(X) means the expected value of XX. Multiply each value by its probability. Then add them all up (Σ\Sigma means add up). The expected value is also called the mean of XX, written μX\mu_X.

E(X)=0+0.3+0.6+0.6+0.4=1.9E(X) = 0 + 0.3 + 0.6 + 0.6 + 0.4 = \mathbf{1.9} goals

What it means: over many games, the team scores about 1.9 goals per game on average. No single game has 1.9 goals. The expected value is a long-run average.

Fair games. A game is fair if the expected value of the money you win or lose is 0.

Example: Roll a number cube. You win $3 if you roll a 6. You pay $1 for any other number. Let XX = the money you win or lose in one game.

E(X)=3⋅16+(−1)⋅56=36−56=−26≈−$0.33E(X) = 3 \cdot \frac{1}{6} + (-1) \cdot \frac{5}{6} = \frac{3}{6} - \frac{5}{6} = -\frac{2}{6} \approx -$0.33

On average you lose about 33 cents a game. The game is not fair.
