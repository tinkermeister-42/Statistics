Glossary

addition rule

\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\). Subtract the overlap because it was counted twice.

See Also: mutually exclusive

association

Two variables are associated when knowing one tells you something about the other. In a two-way table, the conditional percents are different from group to group. An association does not prove that one thing causes the other.

See Also: conditional distribution

bias

When the way data is collected favors some answers over others. A biased sample does not represent the population.

Example:

Voluntary response, convenience, undercoverage, nonresponse, and response bias.

bin

One group of values in a histogram. Each bar of a histogram is one bin.

Example:

The bin “10 to 20” holds every value from 10 up to (but not including) 20.

See Also: histogram

box plot

A graph that shows the five-number summary. A box goes from Q1 to Q3, with a line at the median. Lines called whiskers go out to the minimum and the maximum. If there are outliers, a whisker stops at the last value that is not an outlier.

See Also: five-number summary, quartile

categorical data

Data that puts each answer into a group or category, like “bus, car, or walk.” It is not a measurement.

See Also: two-way table

causation

When one thing actually makes another thing happen. A correlation does not prove causation.

See Also: lurking variable

center

A single number that describes a typical value in a data set. The mean and the median are measures of center.

See Also: mean, median, spread

cluster sample

Split the population into groups (clusters). Then randomly choose some whole clusters and use everyone in them.

See Also: stratified sample

combination

A group where order does not matter. The number of ways to choose \(r\) things from \(n\) is \({}_nC_r = \dbinom{n}{r} = \dfrac{n!}{r!\,(n-r)!}\), read “\(n\) choose \(r\).”

See Also: permutation

complement

The event that \(A\) does not happen. \(P(\text{not } A) = 1 - P(A)\). Some books write \(P(A^C)\).

completely randomized design

An experiment design where chance alone decides which treatment group each subject joins.

See Also: randomized block design, matched pairs

conditional distribution

The percents for one variable inside a single group. Divide each count in that group’s row (or column) by the group’s total.

See Also: marginal distribution, association

conditional probability

The probability of \(A\) when you know \(B\) happened. Written \(P(A \mid B)\) and read “the probability of \(A\) given \(B\).”

\[P(A \mid B) = \frac{P(A \cap B)}{P(B)}\]

control group

The group in an experiment that does not get the new treatment. It may get a placebo or the usual treatment.

See Also: placebo

convenience sample

A sample of people who are easy to reach. It is usually biased.

See Also: bias

correlation coefficient

A number \(r\) from \(-1\) to \(1\) that measures the direction and strength of a linear pattern. Close to \(1\) or \(-1\) is strong. Close to \(0\) is weak.

See Also: scatterplot, causation

counting principle

If one choice has \(m\) options and a second choice has \(n\) options, there are \(m \cdot n\) ways to make both choices.

data

Facts or numbers that we collect to learn about something.

Example:

The number of pets each student in a class has.

dependent events

Events where one happening changes the probability of the other.

Example:

Drawing two marbles without putting the first one back.

See Also: independent events

distribution

All the values in a data set and how often each one happens. A graph of the data shows its distribution.

See Also: shape

dot plot

A graph that puts one dot above a number line for each data value. Dots for the same value stack up.

See Also: frequency table, histogram

double-blind

An experiment where neither the subjects nor the people measuring the results know who got which treatment.

empirical distribution

A probability distribution made from data. Each probability is a count divided by the total.

See Also: theoretical probability

empirical rule

In a normal distribution, about 68% of the data is within 1 standard deviation of the mean, about 95% is within 2, and about 99.7% is within 3. Also called the 68-95-99.7 rule.

See Also: normal distribution

expected payoff

The expected value of the net gain. Let \(X\) = the net gain. Then the expected payoff is \(E(X) = \Sigma\, x \cdot P(x)\). A negative expected payoff means you lose money on average.

See Also: expected value, net gain

expected value

The long-run average of a random variable: \(E(X) = \Sigma\, x \cdot P(x)\). Multiply each value by its probability and add. Also called the mean of \(X\), \(\mu_X\).

See Also: expected payoff

experiment

A study where the researcher gives a treatment on purpose and measures what happens. With random assignment, an experiment can show cause and effect.

See Also: treatment, random assignment

experimental probability

A probability found from trials: the number of times an event happened divided by the number of trials.

See Also: law of large numbers

explanatory variable

The variable a researcher changes, or uses to explain changes in another variable. In a scatterplot, it goes on the \(x\)-axis.

See Also: response variable

extrapolation

Using a line to predict far outside the range of the data. Extrapolation is risky and can give answers that make no sense.

factorial

\(n! = n \cdot (n-1) \cdot (n-2) \cdots 2 \cdot 1\), read “\(n\) factorial.” It counts the ways to arrange \(n\) things in order. By definition, \(0! = 1\).

Example:

\(4! = 4 \cdot 3 \cdot 2 \cdot 1 = 24\)

fair

A way of choosing is fair if every person has the same probability of being chosen. A coin is fair if heads and tails each have probability \(\frac{1}{2}\).

See Also: fair game

fair game

A game where the expected value of the money you win or lose is 0. On average, no one wins or loses money.

fence

A cutoff for outliers. The lower fence is \(Q_1 - 1.5 \times \text{IQR}\). The upper fence is \(Q_3 + 1.5 \times \text{IQR}\). A value outside the fences is an outlier.

See Also: outlier, interquartile range

five-number summary

Five numbers that describe a data set: the minimum, Q1, the median, Q3, and the maximum.

See Also: box plot, quartile

frequency

How many times a value happens in a data set.

Example:

In the data 2, 3, 3, 5, the value 3 has a frequency of 2.

frequency table

A table that lists each value and its frequency.

See Also: frequency, tally

generalize

To say that results from a sample are true for the whole population. This is only safe when the sample was chosen at random.

See Also: sample, population

histogram

A bar graph for number data. The values are put in groups called bins. The bars touch, and the height of each bar is how many values are in that bin.

See Also: bin, dot plot

independent events

Events where one happening does not change the probability of the other. Then \(P(A \cap B) = P(A) \cdot P(B)\), and \(P(A \mid B) = P(A)\).

See Also: dependent events

interquartile range

The distance from Q1 to Q3. It shows how spread out the middle half of the data is. Also called the IQR.

\[\text{IQR} = Q_3 - Q_1\]

See Also: quartile, range

intersection

\(A \cap B\), read “\(A\) intersect \(B\)” or “\(A\) and \(B\).” Both \(A\) and \(B\) happen. In a Venn diagram, it is the overlap.

See Also: union, multiplication rule

IQR

Short for interquartile range: \(Q_3 - Q_1\). It shows how spread out the middle half of the data is.

See Also: interquartile range

law of large numbers

As the number of trials grows, the experimental probability usually gets closer to the theoretical probability.

least-squares regression line

The line that makes \(\Sigma(y - \hat{y})^2\), the sum of the squared residuals, as small as possible.

See Also: residual

line of best fit

A line that follows the trend of the dots in a scatterplot. About the same number of dots are above it as below it. Also called a trend line.

See Also: least-squares regression line, y-hat

lurking variable

A hidden variable that affects both variables in a study. It can make two things look connected when one does not cause the other.

Example:

Hot weather causes both more ice cream sales and more sunburns.

marginal distribution

The percents for one variable, found from the totals in the margins of a two-way table. Divide each total by the grand total.

See Also: conditional distribution

matched pairs

An experiment design with pairs. Each subject gets both treatments in a random order. Or very similar subjects are paired, and each one gets a different treatment.

maximum

The largest value in a data set.

mean

Add up all the values. Then divide by how many values there are. Also called the average.

\[\bar{x} = \frac{\Sigma x}{n}\]

Example:

The mean of 2, 3, 8, 3, 4 is \(20 \div 5 = 4\).

See Also: median

median

The middle value when the data is in order. With an even number of values, the median is halfway between the two middle values.

Example:

The median of 2, 3, 3, 4, 8 is 3.

See Also: mean

minimum

The smallest value in a data set.

mode

The value that happens most often in a data set.

mu

The Greek letter \(\mu\), read “mew.” It stands for the mean of a population, of a normal distribution, or of a random variable (\(\mu_X\)).

See Also: x-bar, sigma

multiplication rule

\(P(A \cap B) = P(A) \cdot P(B \mid A)\). For independent events, this is \(P(A) \cdot P(B)\).

mutually exclusive

Events that cannot happen at the same time. Then \(P(A \cap B) = 0\) and \(P(A \cup B) = P(A) + P(B)\).

n

The number of values in a data set. In \(\bar{x} = \dfrac{\Sigma x}{n}\), you divide by \(n\).

See Also: x-bar, sigma notation

net gain

What you win minus what you paid. It is negative when you lose money.

normal distribution

A bell-shaped, symmetric distribution. Its mean and median are equal and sit in the center. It is described by its mean and its standard deviation.

See Also: empirical rule, z-score

observational study

A study that watches or measures without changing anything. It can show an association but not a cause.

See Also: experiment

outlier

A value that is far away from the rest of the data. A common rule: a value is an outlier if it is more than \(1.5 \times \text{IQR}\) below Q1 or above Q3.

See Also: fence

percentile

The percent of the data that is below a value.

Example:

A score at the 75th percentile is higher than 75% of the scores.

See Also: z-score, quartile

permutation

An arrangement where order matters. The number of ways to arrange \(r\) things chosen from \(n\) is \({}_nP_r = \dfrac{n!}{(n-r)!}\), read “\(n\) permute \(r\).”

See Also: combination

placebo

A fake treatment that looks real, like a sugar pill. People can feel better just from believing they were treated (the placebo effect).

population

The whole group we want to learn about.

Example:

All students at a school. A sample might be 50 of those students.

See Also: sample

probability

A number from 0 to 1 that tells how likely something is. 0 means impossible and 1 means certain. \(P(A)\) is read “the probability of \(A\).”

\[P(A) = \frac{\text{number of ways } A \text{ can happen}}{\text{total number of outcomes}}\]

probability distribution

A list or graph of every value of a random variable and its probability. Every probability is from 0 to 1, and they add to 1: \(\Sigma P(x) = 1\).

See Also: random variable, expected value

quartile

The three values that cut ordered data into four parts with the same number of values. Q1 is the median of the lower half. The median is Q2. Q3 is the median of the upper half.

See Also: five-number summary, interquartile range

random assignment

Using chance to decide which subjects get which treatment. It makes the groups alike, so a difference can be blamed on the treatment.

See Also: experiment

random variable

A number that comes from a chance process, such as the number of heads in 3 coin flips. It is often written with a capital letter, like \(X\).

See Also: probability distribution

randomized block design

An experiment design that first splits the subjects into groups that are alike (blocks). Then the treatments are randomly assigned inside each block.

See Also: completely randomized design, matched pairs

range

The maximum minus the minimum. It shows how spread out all the data is.

See Also: interquartile range

relative frequency

A count divided by a total, written as a fraction, decimal, or percent.

Example:

12 out of 60 students is a relative frequency of \(\frac{12}{60} = 20\%\).

See Also: frequency, two-way table

replication

Using many subjects in an experiment. With more subjects, chance differences between the groups get smaller.

See Also: experiment, random assignment

residual

The actual value minus the predicted value: \(y - \hat{y}\). A positive residual means the point is above the line.

See Also: residual plot, least-squares regression line

residual plot

A graph of the residuals against \(x\). Random scatter means a line is a good model. A pattern, like a curve, means it is not.

See Also: residual

response variable

The variable that is measured to see the effect. In a scatterplot, it goes on the \(y\)-axis.

See Also: explanatory variable

sample

A part of a group that we collect data from. We use the sample to learn about the whole group (the population).

See Also: population

sample survey

A study that asks a sample of people questions.

See Also: observational study, experiment

scatterplot

A graph of two numbers for each person or thing. Each dot shows one pair \((x, y)\).

See Also: line of best fit, correlation coefficient

segmented bar chart

A bar chart where each bar is 100% of one group, split into parts. It shows conditional distributions side by side.

See Also: conditional distribution

shape

What a graph of the data looks like: symmetric, skewed left, or skewed right.

See Also: symmetric, skewed left, skewed right

sigma

The small Greek letter \(\sigma\). It stands for the standard deviation of a population or of a normal distribution. The capital letter \(\Sigma\) means something different: add up.

See Also: standard deviation, mu

simple random sample

A sample where every group of people of that size has the same chance of being chosen. Also called an SRS.

See Also: stratified sample

simulation

Using random numbers or shuffling to copy a chance process many times, to see what usually happens.

See Also: statistically significant

skewed left

A shape where most values are high and a long tail stretches to the left. The mean is less than the median.

See Also: skewed right, tail

skewed right

A shape where most values are low and a long tail stretches to the right. The mean is greater than the median.

Example:

US household income is skewed right.

See Also: skewed left, tail

slope

How much \(y\) changes when \(x\) goes up by 1. For a line of best fit, when \(x\) goes up by 1, the predicted \(y\) changes by the slope.

See Also: y-intercept

spread

How far apart the values in a data set are. The range, the IQR, and the standard deviation are measures of spread.

See Also: range, interquartile range, standard deviation

standard deviation

A number that tells how far the values in a data set usually are from the mean. A small standard deviation means the values are close to the mean. It is often written \(s\) (for a sample) or SD.

\[s = \sqrt{\frac{\Sigma(x - \bar{x})^2}{n - 1}}\]

See Also: variance, mean

statistically significant

A result that would rarely happen by chance alone. Usually this means less than 5% of the time.

See Also: simulation

stratified sample

Split the population into groups that are alike (strata). Then take a random sample from each group.

See Also: cluster sample

symmetric

A shape where the left side and the right side look about the same. The mean and the median are about equal.

systematic sample

Pick a random starting point. Then choose every \(k\)th person on a list.

tail

The long, low side of a graph. The mean is pulled toward the tail.

tally

A mark made for each data value as you count it.

theoretical distribution

A probability distribution found by reasoning about the chance process (equally likely outcomes, or the multiplication rule), not from data.

See Also: empirical distribution, probability distribution

theoretical probability

A probability found by reasoning about equally likely outcomes.

See Also: experimental probability

treatment

What the researcher does to the subjects in an experiment.

See Also: experiment, control group

tree diagram

A diagram with branches that shows each stage of a chance process. Multiply along a path to find the probability of that path.

trial

One run of a chance process, such as one flip of a coin or one set of 3 free throws in a simulation.

two-way table

A table that shows counts for two categorical variables at once. The groups of one variable name the rows. The groups of the other variable name the columns. The totals are in the margins.

See Also: relative frequency, venn diagram

union

\(A \cup B\), read “\(A\) union \(B\)” or “\(A\) or \(B\).” \(A\) happens, \(B\) happens, or both happen.

See Also: intersection, addition rule

variance

The standard deviation squared. To find it, add the squared differences from the mean and divide by \(n - 1\).

See Also: standard deviation

Venn diagram

A picture that uses overlapping circles to show groups. The overlap shows what is in both groups. The space outside the circles shows what is in neither.

See Also: two-way table

whisker

A line on a box plot that goes from the box out to the smallest or largest value that is not an outlier.

See Also: box plot

with replacement

Each item is put back before the next draw. Every draw has the same probabilities, so the draws are independent.

See Also: without replacement, independent events

without replacement

Each item stays out after it is drawn. The probabilities change from one draw to the next, so the draws are dependent.

See Also: with replacement, dependent events

x-bar

The symbol \(\bar{x}\), read “x-bar.” It stands for the mean of a sample: \(\bar{x} = \dfrac{\Sigma x}{n}\).

See Also: mean, mu

y-hat

The symbol \(\hat{y}\), read “y-hat.” It stands for a predicted value of \(y\) from a line, such as \(\hat{y} = 5x + 54\).

See Also: residual

y-intercept

The value of \(y\) when \(x = 0\). For a line of best fit, it is the predicted \(y\) when \(x = 0\). Sometimes it has no real meaning.

See Also: slope

z-score

How many standard deviations a value is above or below the mean. A positive z-score is above the mean. A negative z-score is below the mean.

\[z = \frac{x - \mu}{\sigma}\]

See Also: standard deviation, percentile

z-table

A table that gives the area under the standard normal curve to the left of a z-score. That area is the proportion of the data below the z-score.

See Also: z-score, normal distribution

Σ (sigma notation)

\(\Sigma\) is the Greek capital letter sigma. In statistics it means add up.

Example:

For the data 2, 3, 5: \(\Sigma x = 2 + 3 + 5 = 10\).

See Also: x-bar, mean
